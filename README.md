# Ring Shop
This is a website for a store that sells silver items, as like rings, necklaces, bracelets and earrings. The website is built with a backend using C# and frontend using JavaScript/React

# Technologies

## Backend

### C#
- ASP.NET Core
	> Minimal APIs	 
- Entity Framework Core
	> LINQ
- MySQL 
- Docker
	> Redis
- Authentication
	> JWT
- Cloudinary

## Frontend
### JavaScript, HTML, CSS
- React
	> Hooks
	> Mercado Pago SDK

# Getting Started
- Clone the repository
- Install the dependencies for the backend and frontend
- Update the .env file and user secrets with your own credentials
	> - MySQL database connection string 
	> - Cloudinary credentials
	> - Mercado Pago credentials
	> - JWT secret key
	> - Redis connection string

- Run the backend and frontend servers
